Temperature Monitor and Alarm Checker
What it does
The Temperature Monitor and Alarm Checker is a Python program designed to monitor machine temperature readings.
My own twist
I added a Machine Condition Status Report.
NORMAL: Highest reading is 60°C or below.
WARNING: Highest reading is above 60°C but not above 80°C.
CRITICAL: Highest reading is above 80°C.
What I learned
I learned how to use Python functions, loops, conditional statements and lists.
